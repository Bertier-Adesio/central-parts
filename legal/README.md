# Cadre contractuel

Gabarits de documents contractuels, en version de travail.

## À rédiger

- [ ] Conditions générales de vente (acheteurs).
- [ ] Contrat distributeur partenaire (publication du stock, cotations, paiement, logistique, vérification des agréments fabricants).
- [ ] Contrat d'accès API (canaux partenaires).
- [ ] Mentions légales et politique de confidentialité du site : brouillons FR/EN/中文 dans [`brouillons/`](brouillons/), non publiés, à valider (champs [À VALIDER] et [À COMPLÉTER]).

Seuls des gabarits sans données personnelles ni montants négociés sont versionnés ici.
