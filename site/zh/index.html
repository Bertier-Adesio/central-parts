保障

无中间商，无灰色渠道。每家分销商均获其所代理制造商的授权。

可追溯

常见问题

元器件由谁销售？

由网络中的授权分销商销售。Central.Parts 负责搜索、询价与下单。

询价如何进行？

填写料号、数量与期望日期，请求将发送给相关分销商，您将收到附带跟踪编号的回复。

服务哪些地区？

欧洲、美洲与中国，价格以当地币种显示。

能否接入我的 ERP？

可以，通过 API 接入。请在联系表单中申请权限。

如何成为合作分销商？

填写表单并选择“分销商”。开通账户前我们将核实您的制造商授权。
