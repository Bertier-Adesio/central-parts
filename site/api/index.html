PrincipeHow it works基本原理

Les plateformes de chiffrage et d’achat (outils de nomenclature, ERP, sites partenaires) interrogent Central.Parts comme elles interrogent un distributeur : une seule API d’offres, une seule clé. Derrière, Central.Parts agrège ses fournisseurs (fabricants, distributeurs, revendeurs, brokers) sans jamais les nommer. Chaque offre indique sa catégorie de source et porte des paliers de prix comparables, palier par palier, avec ceux de vos autres fournisseurs.

Costing and purchasing platforms (BOM tools, ERPs, partner sites) query Central.Parts the way they query a distributor: one offers API, one key. Behind it, Central.Parts aggregates its suppliers (manufacturers, distributors, resellers, brokers) without ever naming them. Every offer states its source category and carries price breaks you can compare, break by break, with those of your other suppliers.

报价与采购平台（BOM 工具、ERP、合作网站）可以像查询分销商一样查询 Central.Parts：一个报价 API，一把密钥。Central.Parts 在后台汇总其供应商（制造商、分销商、贸易商、经纪商），但从不透露其名称。每条报价都标明来源类别，并提供价格阶梯，可与您其他供应商的报价逐档比较。

Chaque offre, tracée jusqu’à sa source. Every offer, traced to its source. 每条报价，均可追溯至来源。

ConventionsConventions通用约定

  • JSON en UTF-8, dates ISO 8601, montants en nombres décimaux.
  • Idempotence : en-tête Idempotency-Key sur les écritures ; un même appel rejoué dans les 24 h renvoie la même réponse sans double effet.
  • Limites d’appels par clé, indiquées dans les en-têtes X-RateLimit-*.
  • JSON in UTF-8, ISO 8601 dates, amounts as decimal numbers.
  • Idempotency: Idempotency-Key header on writes; the same call replayed within 24 h returns the same response with no double effect.
  • Call limits per key, stated in the X-RateLimit-* headers.
  • JSON 采用 UTF-8 编码，日期采用 ISO 8601，金额为十进制数。
  • 幂等：写操作使用 Idempotency-Key 请求头；24 小时内重放同一调用返回相同响应，不会重复执行。
  • 按密钥限制调用频率，限额见 X-RateLimit-* 响应头。

PrixPrices价格

Le prix publié est tout compris. Aucune marge n’est ajoutée après. Pour une offre de broker ou de surplus, le détail (prix d’achat converti, commission, frais) est remis à la commande. Test en laboratoire, transport et échantillons : options facturées à part.

The published price is all-inclusive. No margin is added afterwards. For a broker or surplus offer, the breakdown (converted purchase price, commission, fees) is provided with the order. Laboratory testing, transport and samples: options invoiced separately.

公布的价格为含全部费用的总价，之后不再加价。对于经纪商或库存余货报价，明细（换算后的采购价、佣金、费用）在下单时提供。实验室检测、运输和样品为另行收费的选项。
